# Week 10 — Transaction Management

## Transactions and ACID

| Property | Required behaviour |
| --- | --- |
| Atomicity | All effects occur or none do |
| Consistency | A valid state is transformed into another valid state |
| Isolation | Concurrent execution behaves like an accepted serial order |
| Durability | Committed effects survive failure |

`COMMIT` makes a transaction successful while `ROLLBACK` removes its uncommitted
effects

## Schedules and conflicts

A schedule interleaves operations while preserving each transaction's own
operation order

Two operations conflict when they:

1. belong to different transactions
2. access the same data item
3. include at least one write

Therefore `read-read` does not conflict, while `read-write`, `write-read` and
`write-write` do

## Common anomalies

| Anomaly | Pattern |
| --- | --- |
| Lost update | One write overwrites another transaction's update |
| Dirty read | A transaction reads data written by an uncommitted transaction |
| Non-repeatable read | Re-reading a row returns a changed value |
| Incorrect summary | An aggregate mixes values from different logical moments |

## Recoverability levels

If $T_j$ reads a value written by $T_i$:

- **recoverable** requires $T_i$ to commit before $T_j$ commits
- **cascadeless** requires $T_i$ to commit before $T_j$ reads that value
- **strict** prevents other transactions reading or writing the item until
  $T_i$ commits or aborts

Strict schedules are cascadeless, and cascadeless schedules are recoverable

## Conflict serialisability

Build a precedence graph with one node per transaction

For every conflicting pair where an operation of $T_i$ occurs before the
conflicting operation of $T_j$, add edge $T_i\rightarrow T_j$

- an acyclic graph means the schedule is conflict-serialisable
- a topological ordering gives an equivalent serial order
- a cycle means no equivalent serial order exists under conflict equivalence

Serialisability and recoverability answer different questions, so a schedule
must be checked for both when both properties are required
