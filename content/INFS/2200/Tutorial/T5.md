# Tutorial 5 — Storage Calculations

## Fixed-length file example

Suppose a block holds 4096 bytes, each record uses 180 bytes and the file has
50,000 unspanned records

$$
bfr=\left\lfloor\frac{4096}{180}\right\rfloor=22
$$

$$
b=\left\lceil\frac{50000}{22}\right\rceil=2273\text{ blocks}
$$

Unused bytes per non-final block are:

$$
4096-(22\times180)=136\text{ bytes}
$$

## Access-cost comparisons

For $b$ blocks:

- unordered equality search averages roughly $b/2$ block reads when the row exists
- binary search on ordered blocks takes roughly $\lceil\log_2 b\rceil$ probes
- a well-distributed static hash file aims for the home bucket plus any overflow

These are simplified models, so state whether the target exists, blocks are
cached and overflow pages are ignored

## File-choice prompts

- frequent append and full scan → heap
- ordered report or range predicate → sequential
- equality on a stable hash key → hash

## Error traps

- using ceiling for blocking factor instead of floor
- dividing record count by bytes
- forgetting overflow blocks or page headers
- claiming record-level I/O when storage transfers whole blocks
