# Tutorial 6 — Index Selection

## Classify before calculating

Ask:

1. is the data file physically ordered on this field
2. is the field unique
3. is there one entry per record, value or block
4. does the pointer target a record, bucket or block

This separates primary, clustering and secondary indexes before any block
calculation

## Index block calculation

If an index entry uses $I$ bytes and an index block uses $B$ bytes:

$$
bfr_I=\left\lfloor\frac{B}{I}\right\rfloor
$$

For $r_I$ entries:

$$
b_I=\left\lceil\frac{r_I}{bfr_I}\right\rceil
$$

Repeat the calculation level by level until the top level fits in one block

## Trace a B+ tree update

For insertion:

1. descend to the target leaf
2. insert in key order
3. split an overflowing leaf and copy its separator upward
4. recursively split overflowing internal nodes
5. create a new root if the old root splits

For range search, descend once then follow the linked leaves

## Pick the access path

- equality and no ordering → consider hash
- range or ordered output → B+ tree
- low-cardinality analytical filters → bitmap
- frequent writes → count index maintenance before adding another index
