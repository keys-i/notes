# Practical 1 — PostgreSQL Setup and CRUD

## UQZone workflow

The course zone provides three useful entry points

- VS Code in the browser for files and an integrated terminal
- WeTTY for terminal access
- pgAdmin for graphical database inspection

The terminal route is the main path for these practicals, while an SSH client
can connect through the EAIT network or UQ VPN

## Start a practical database

Open `psql`, create a separate database and connect to it

```sql
CREATE DATABASE prac1;
\c prac1
```

Useful `psql` commands

| Command | Purpose |
| --- | --- |
| `\?` | Show `psql` help |
| `\d EMP` | Describe a table |
| `\dt` | List tables |
| `\i file.sql` | Run a SQL source file |
| `\q` | Exit `psql` |

## Create and reshape a table

```sql
CREATE TABLE EMPLOYEE (
    EMPNO INTEGER PRIMARY KEY,
    ENAME VARCHAR(20),
    JOB VARCHAR(20),
    MGR INTEGER,
    HIREDATE VARCHAR(20),
    SALARY NUMERIC(7,2),
    COMM NUMERIC(7,2)
);
```

`ALTER TABLE` changes the schema without recreating the table

```sql
ALTER TABLE EMPLOYEE RENAME COLUMN SALARY TO SAL;

ALTER TABLE EMPLOYEE
ALTER COLUMN HIREDATE TYPE DATE
USING HIREDATE::DATE;

ALTER TABLE EMPLOYEE ADD DEPTNO INTEGER;
ALTER TABLE EMPLOYEE DROP COLUMN COMM;
ALTER TABLE EMPLOYEE RENAME TO EMP;
```

The `USING` expression tells PostgreSQL how to convert existing values when a
column type changes

## CRUD pattern

```sql
INSERT INTO EMP VALUES (
    1001, 'JOHN CLAY', 'ACCOUNTANT', NULL,
    '2010-12-17', 75000, 10
);

SELECT EMPNO, ENAME
FROM EMP
WHERE DEPTNO = 30;

UPDATE EMP
SET SAL = SAL * 1.1
WHERE DEPTNO = 10;

DELETE FROM EMP
WHERE EMPNO = 1005;
```

Always run a matching `SELECT` before a broad `UPDATE` or `DELETE` so the target
rows are visible first

## Run a saved script

Keep repeatable setup in a `.sql` file, then load it from `psql`

```sql
\i sol.sql
```

This is faster to rerun, easier to debug and leaves an editable record of the
database setup

## Checkpoint

- the prompt changes after connecting to `prac1`
- `\d EMP` shows the renamed and converted columns
- inserted rows appear in `SELECT * FROM EMP`
- update and delete counts match the intended number of rows
