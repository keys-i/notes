# COMP4702 Machine Learning

Learn the ideas, calculate with them, then decide when each model is suitable.
The path follows the current UQ course scope: conceptual, computational,
mathematical and statistical foundations; supervised and unsupervised learning;
neural networks; experimentation; and generative models.

The [Semester 1, 2026 course profile](https://course-profiles.uq.edu.au/course-profiles/COMP4702-21208-7620)
is the source for the current course scope and assessment format. These notes are
original explanations and practice, not a copy of the course material.

## Mastery path

1. [Frame a learning problem](Lectures/foundations.md): data, model, loss,
   optimisation and generalisation
2. [Build linear models](Lectures/linear.md): regression, classification and
   gradient updates
3. [Reason with trees](Lectures/trees.md): splits, impurity, pruning and
   ensembles
4. [Understand neural networks](Lectures/neural.md): representations, forward
   passes and backpropagation
5. [Evaluate honestly](Lectures/evaluation.md): splits, metrics, leakage and
   experimental design
6. [Find structure without labels](Lectures/unsupervised.md): clustering,
   dimensionality reduction and semi-supervised learning
7. [Model how data is made](Lectures/generative.md): likelihoods, latent
   variables and modern generative models

Each topic gives you a mental model, the useful mathematics, a worked example,
a common mistake, a hidden-answer check and a short link to assessment-style
reasoning.
