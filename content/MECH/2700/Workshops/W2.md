data range

## Lagrange form

$$
p_n(x)=\sum_{i=0}^{n}y_iL_i(x),
\qquad
L_i(x)=\prod_{\substack{j=0\\j\ne i}}^{n}
\frac{x-x_j}{x_i-x_j}
$$

```python
import numpy as np


def lagrange(x_data, y_data, x):
    result = np.zeros_like(x, dtype=float)
    for i, y_i in enumerate(y_data):
        basis = np.ones_like(x, dtype=float)
        for j, x_j in enumerate(x_data):
            if i != j:
                basis *= (x - x_j) / (x_data[i] - x_j)
        result += y_i * basis
    return result
```

## Plot

```python
alpha_plot = np.linspace(alpha.min(), alpha.max(), 500)
lift_plot = lagrange(alpha, lift, alpha_plot)
drag_plot = lagrange(alpha, drag, alpha_plot)

ax.plot(alpha_plot, lift_plot, label="lift")
ax.plot(alpha_plot, drag_plot, label="drag")
ax.scatter(alpha, lift)
ax.scatter(alpha, drag)
ax.set_xlabel("angle of attack (degrees)")
ax.set_ylabel("force (N)")
ax.grid()
ax.legend()
```

## Checks

- $p_n(x_i)=y_i$ at every tabulated angle
- the input angles are distinct
- do not extrapolate beyond the supplied angle range
- inspect oscillation between points before trusting a high-degree fit
