# Week 13 — Course Review

## Method selection

| Problem                                 | Method to reach for                                |
| --------------------------------------- | -------------------------------------------------- |
| Values between tabulated points         | Lagrange or Newton interpolation                   |
| Integral from equally spaced samples    | Composite trapezoidal or Simpson rule              |
| Small dense linear system               | Pivoted elimination or LU                          |
| Large sparse diagonally dominant system | Gauss-Seidel or SOR                                |
| Initial-value ODE                       | Euler, RK2 or RK4                                  |
| Bracketed scalar root                   | Bisection                                          |
| Smooth scalar root with a good guess    | Newton or secant                                   |
| Unimodal scalar minimum                 | Golden-section search                              |
| Parabolic PDE                           | Explicit or implicit time stepping                 |
| Hyperbolic PDE                          | Upwind or centred wave update with a CFL check     |
| Elliptic PDE                            | Five-point stencil and a linear or iterative solve |

## Calculation checklist

1. write the continuous model and conditions
2. define the grid, step size or iteration index
3. write the numerical formula before substituting values
4. keep old and new states distinct
5. state the stopping or stability condition
6. calculate a residual, error estimate or refinement comparison
7. check units, signs, boundaries and limiting cases

## Fast drills

- derive a centred first derivative and state its error order
- write Simpson weights for eight panels
- perform one Jacobi and one Gauss-Seidel sweep from the same initial vector
- convert a second-order ODE into two first-order equations
- identify when Newton iteration can fail
- calculate a one-dimensional heat-equation stability limit
- write an upwind update for both signs of velocity
- assemble one interior and one boundary row for Laplace equation

## Final checks

- a small step is not enough when the residual is large
- a small residual does not guarantee accuracy for an ill-conditioned system
- an explicit PDE update is unusable when its stability limit is violated
- a converged answer still needs boundary and conservation checks
