# Week 6 — Catalytic Converter

## Concentration model

The flow-only model is

$$
V\frac{dc}{dx}=-Kc,
\qquad
V=0.1\ \mathrm{m\,s^{-1}},\quad K=0.6\ \mathrm{s^{-1}}
$$

For $c(0)=500\ \mathrm{ppm}$ and $L=0.5\ \mathrm m$,

$$
c(L)=c(0)e^{-KL/V}
$$

Including diffusion with $D=10^{-3}\ \mathrm{m^2\,s^{-1}}$ gives

$$
V\frac{dc}{dx}=-Kc+D\frac{d^2c}{dx^2}
$$

Using centred differences at an interior node,

$$
\left(\frac{D}{\Delta x^2}+\frac{V}{2\Delta x}\right)c_{i-1}
-\left(\frac{2D}{\Delta x^2}+K\right)c_i
+\left(\frac{D}{\Delta x^2}-\frac{V}{2\Delta x}\right)c_{i+1}=0
$$

Use $\Delta x=L/n$ and assemble the boundary and interior equations into

$$
A\mathbf c=\mathbf b
$$

## Jacobi and Gauss-Seidel

$$
c_i^{(m+1)}=
\frac{b_i-\sum_{j\ne i}A_{ij}c_j^*}{A_{ii}}
$$

Jacobi uses only values from iteration $m$

Gauss-Seidel uses each new value as soon as it is available

```python
def gauss_seidel(A, b, concentration):
    updated = concentration.copy()
    for i in range(len(b)):
        lower = A[i, :i] @ updated[:i]
        upper = A[i, i + 1 :] @ concentration[i + 1 :]
        updated[i] = (b[i] - lower - upper) / A[i, i]
    return updated
```

## Convergence loop

```python
for _ in range(maximum_iterations):
    updated = gauss_seidel(A, b, concentration)
    change = np.linalg.norm(updated - concentration, np.inf)
    residual = np.linalg.norm(A @ updated - b, np.inf)
    concentration = updated
    if change <= tolerance and residual <= tolerance:
        break
else:
    raise RuntimeError("iteration did not converge")
```

## Checks

- inspect diagonal dominance before iterating
- Jacobi must not update the old vector in place
- use $\Delta x=L/n$, not $n/L$
- concentration should respect the boundary conditions
- report both iteration count and final residual
- compare against a direct solve while debugging
