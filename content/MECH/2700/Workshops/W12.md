# Week 12 — Soap Film Geometry

## Model

The equilibrium height $u(x,y)$ of a small-slope soap film satisfies

$$
\nabla^2u=0
$$

The wire frame supplies Dirichlet boundary values around the domain

## Five-point stencil

For equal grid spacing $h$

$$
u_{i,j}
=
\frac14
\left(
u_{i+1,j}+u_{i-1,j}+u_{i,j+1}+u_{i,j-1}
\right)
$$

## Matrix-free Gauss-Seidel

```python
for _ in range(maximum_sweeps):
    largest_change = 0.0
    for j in range(1, ny - 1):
        for i in range(1, nx - 1):
            old = height[j, i]
            height[j, i] = 0.25 * (
                height[j, i + 1]
                + height[j, i - 1]
                + height[j + 1, i]
                + height[j - 1, i]
            )
            largest_change = max(largest_change, abs(height[j, i] - old))
    if largest_change <= tolerance:
        break
```

## Residual

$$
r_{i,j}
=
\frac{u_{i+1,j}-2u_{i,j}+u_{i-1,j}}{h^2}
+
\frac{u_{i,j+1}-2u_{i,j}+u_{i,j-1}}{h^2}
$$

## Checks

- never update prescribed boundary nodes
- report the maximum interior residual
- the solution stays inside the boundary extrema
- symmetry in the frame should produce symmetry in the film
- refine the grid and compare the centre height
