# Week 7 - Ordinary Differential Equations

## Initial Value Problems

An ordinary differential equation relates a function to its derivatives

For a first-order initial value problem

$$
\frac{dy}{dt}=f(t,y),
\qquad
y(t_0)=y_0
$$

the numerical solution advances through discrete times

$$
t_j=t_0+jh,
\qquad
y_j\approx y(t_j)
$$

where $h$ is the step size

| Method type | Dependence                                                  |
| ----------- | ----------------------------------------------------------- |
| Single-step | Uses only the previous solution value                       |
| Multi-step  | Uses several previous values and needs a starting procedure |

MECH2700 focuses on single-step methods

## Euler's Method

Expand $y(t_{j+1})$ about $t_j$

$$
y(t_{j+1})
=
y(t_j)
+hy'(t_j)
+\frac{h^2}{2}y''(t_j)
+\cdots
$$

Truncating after the first derivative gives

$$
y_{j+1}
=
y_j+hf(t_j,y_j)
$$

| Error                              | Order    |
| ---------------------------------- | -------- |
| Local error in one step            | $O(h^2)$ |
| Global error over a fixed interval | $O(h)$   |

The global error is one order lower because approximately $(t_f-t_0)/h$
local errors accumulate

```python
def euler_step(f, t, y, h):
    return y + h * f(t, y)
```

> [!EXAMPLE]- Newton's law of cooling
> For
>
> $$
> \frac{dT}{dt}=-k(T-T_a)
> $$
>
> Euler gives
>
> $$
> T_{j+1}
> =
> (1-kh)T_j+khT_a
> $$
>
> The transient is multiplied by $1-kh$ each step, so stability requires
>
> $$
> |1-kh|\le1
> \quad\Longrightarrow\quad
> 0\le h\le\frac{2}{k}
> $$

## Modified Euler Method

Euler uses only the slope at the beginning of the step

Modified Euler predicts the endpoint, evaluates the endpoint slope, then
averages both slopes

### Predictor

$$
\widehat y_{j+1}
=
y_j+hf(t_j,y_j)
$$

### Corrector

$$
y_{j+1}
=
y_j
+\frac{h}{2}
\left[
f(t_j,y_j)
+f(t_j+h,\widehat y_{j+1})
\right]
$$

| Error        | Order    |
| ------------ | -------- |
| Local error  | $O(h^3)$ |
| Global error | $O(h^2)$ |

```python
def modified_euler_step(f, t, y, h):
    prediction = y + h * f(t, y)
    return y + 0.5 * h * (f(t, y) + f(t + h, prediction))
```

The corrector can be repeated, but a higher-order Runge-Kutta method is
usually a better use of extra function evaluations

## Runge-Kutta Methods

Runge-Kutta methods achieve higher-order accuracy using several slope
evaluations without requiring analytical higher derivatives

An $m$-stage method has the form

$$
y_{j+1}=y_j+\sum_{i=1}^{m}\alpha_i k_i
$$

where each $k_i$ is a slope evaluated at an intermediate point

### Second-Order Runge-Kutta Family

The 2021 exam writes every two-stage RK2 method using one parameter
$\alpha\ne0$

$$
s_1=f(t_j,y_j)
$$

$$
s_2=f\left(t_j+\alpha h,\ y_j+\alpha h s_1\right)
$$

$$
\boxed{
y_{j+1}
=y_j+h\left[
\left(1-\frac{1}{2\alpha}\right)s_1
+\frac{1}{2\alpha}s_2
\right]}
$$

Changing $\alpha$ changes where the second slope is sampled and how the two
slopes are weighted

| Method   | $\alpha$ | Second-stage point | Weights on $(s_1,s_2)$ |
| -------- | -------- | ------------------ | ---------------------- |
| Heun     | $1$      | endpoint           | $(1/2,1/2)$            |
| midpoint | $1/2$    | midpoint           | $(0,1)$                |
| Ralston  | $2/3$    | two-thirds point   | $(1/4,3/4)$            |

Heun is the modified Euler predictor-corrector written as a two-stage RK
method

All three methods use two function evaluations and have local error $O(h^3)$
and global error $O(h^2)$

> [!EXAM] Apply the requested RK2 variant
>
> 1. substitute the specified $\alpha$ before calculating any weights
> 2. calculate $s_1$ from the original state
> 3. calculate the intermediate time and state for $s_2$
> 4. combine the two slopes using the weights in the formula
>
> The $s_i$ above are unscaled slopes, so the final combination needs the
> outside factor $h$

## Classical Fourth-Order Runge-Kutta

$$
k_1=hf(t_j,y_j)
$$

$$
k_2
=
hf\left(t_j+\frac h2,y_j+\frac{k_1}{2}\right)
$$

$$
k_3
=
hf\left(t_j+\frac h2,y_j+\frac{k_2}{2}\right)
$$

$$
k_4=hf(t_j+h,y_j+k_3)
$$

$$
y_{j+1}
=
y_j+\frac{k_1+2k_2+2k_3+k_4}{6}
$$

| Error        | Order    |
| ------------ | -------- |
| Local error  | $O(h^5)$ |
| Global error | $O(h^4)$ |

```python
def rk4_step(f, t, y, h):
    k1 = h * f(t, y)
    k2 = h * f(t + h / 2, y + k1 / 2)
    k3 = h * f(t + h / 2, y + k2 / 2)
    k4 = h * f(t + h, y + k3)
    return y + (k1 + 2 * k2 + 2 * k3 + k4) / 6
```

RK4 usually gives more accuracy per function evaluation than repeatedly
shrinking the step of a low-order method

## Error and Stability

Accuracy and stability are different requirements

| Question               | Meaning                                                |
| ---------------------- | ------------------------------------------------------ |
| Is the result stable   | Numerical disturbances remain bounded                  |
| Is the result accurate | The stable result is close enough to the true solution |

A stable step can still be much too large for the required accuracy

For a method with global error $O(h^p)$, halving $h$ should reduce the error by
approximately $2^p$

| Method                | Global order | Expected error reduction when $h$ halves |
| --------------------- | -----------: | ---------------------------------------: |
| Euler                 |          $1$ |                                      $2$ |
| Modified Euler or RK2 |          $2$ |                                      $4$ |
| RK4                   |          $4$ |                                     $16$ |

> [!EXAM] Cost comparison
>
> Compare methods using both error order and function evaluations
>
> Two Euler half-steps and one RK2 step each require two function evaluations,
> but RK2 has global error $O(h^2)$ while Euler remains first order

## Embedded Runge-Kutta and Step Control

Repeating an RK4 step using two half-steps estimates error but requires many
extra function evaluations

Runge-Kutta-Fehlberg instead uses a shared set of stages to produce fourth-
and fifth-order estimates

1. compute both estimates from the same stages
2. estimate error from their difference
3. accept the higher-order value if the error is within tolerance
4. reject and repeat with a smaller $h$ otherwise
5. choose the next $h$ from the observed error

Adaptive steps use small $h$ where the solution changes rapidly and large $h$
where it is smooth

## Higher-Order ODEs

Convert an $n$th-order ODE into a system of $n$ first-order ODEs

For

$$
y^{(n)}
=
f(t,y,y',\ldots,y^{(n-1)})
$$

define

$$
z_1=y,
\quad
z_2=y',
\quad\ldots\quad,
z_n=y^{(n-1)}
$$

Then

$$
\begin{aligned}
z_1'&=z_2\\
z_2'&=z_3\\
&\ \vdots\\
z_{n-1}'&=z_n\\
z_n'&=f(t,z_1,z_2,\ldots,z_n)
\end{aligned}
$$

or in vector form

$$
\mathbf z'=\mathbf f(t,\mathbf z)
$$

All scalar stepping formulas then apply componentwise to $\mathbf z$

> [!EXAMPLE]- Projectile motion
> With no drag
>
> $$
> \ddot x=0,
> \qquad
> \ddot y=-g
> $$
>
> define
>
> $$
> \mathbf z=
> \begin{bmatrix}
> z_1\\z_2\\z_3\\z_4
> \end{bmatrix}
> =
> \begin{bmatrix}
> x\\\dot x\\y\\\dot y
> \end{bmatrix}
> $$
>
> giving
>
> $$
> \mathbf z'
> =
> \begin{bmatrix}
> z_2\\0\\z_4\\-g
> \end{bmatrix}
> $$

<!-- -->

> [!EXAMPLE]- Nonlinear beam equation
> For
>
> $$
> EI\frac{y''}{[1+(y')^2]^{3/2}}=M(x)
> $$
>
> let $z_1=y$ and $z_2=y'$
>
> $$
> \begin{aligned}
> z_1'&=z_2\\
> z_2'&=\frac{M(x)}{EI}(1+z_2^2)^{3/2}
> \end{aligned}
> $$

## Time-Marching Pattern

```python
t = t0
y = np.array(y0, dtype=float)
times = [t]
states = [y.copy()]

while t < final_time:
    step = min(h, final_time - t)
    y = rk4_step(f, t, y, step)
    t += step
    times.append(t)
    states.append(y.copy())
```

Use `.copy()` when recording array states so history entries do not all refer
to the same mutable array

> [!EXAM] Worked ODE workflow
>
> 1. convert every higher-order equation to first-order form
> 2. write the state-vector order explicitly
> 3. substitute the initial conditions into that order
> 4. compute each stage from the correct intermediate state
> 5. advance both $t$ and the full state vector
> 6. state local or global error exactly as requested
> 7. discuss stability separately from accuracy

---

> [!NOTE] Key ideas
>
> - Euler is first-order accurate globally
> - Modified Euler is a second-order predictor-corrector method
> - Classical RK4 has global error $O(h^4)$
> - Higher order can provide better accuracy for the same evaluation cost
> - Adaptive methods estimate error and vary the step size
> - Any higher-order ODE can be rewritten as a first-order vector system
> - A stable result is not automatically an accurate result
