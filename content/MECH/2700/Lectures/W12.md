# Week 12 - Elliptic Equations

## Elliptic Boundary-Value Problems

Elliptic PDEs describe steady fields whose values are influenced by boundaries
throughout the domain

The canonical two-dimensional example is Laplace's equation

$$
\boxed{\nabla^2u
=\frac{\partial^2u}{\partial x^2}
+\frac{\partial^2u}{\partial y^2}=0}
$$

With a source term, Poisson's equation is

$$
\nabla^2u=f(x,y)
$$

Applications include steady heat conduction, potential flow, electrostatic
potential and membrane deflection

There is no time derivative and therefore no initial condition

## Boundary Conditions

### Dirichlet Condition

The value is specified on a boundary

$$
u=u_b
$$

### Neumann Condition

The normal gradient or flux is specified

$$
\frac{\partial u}{\partial n}=g
$$

At a right boundary, a first-order one-sided approximation is

$$
\frac{u_{m-1,j}-u_{m-2,j}}{\Delta x}=g(y_j)
$$

Only values inside the domain are used

> [!WARNING] A pure Neumann problem needs a reference value
>
> The prescribed fluxes must also satisfy a compatibility condition

## Five-Point Laplace Stencil

At an interior node $(i,j)$

$$
u_{xx}
\approx
\frac{u_{i+1,j}-2u_{i,j}+u_{i-1,j}}{\Delta x^2}
$$

$$
u_{yy}
\approx
\frac{u_{i,j+1}-2u_{i,j}+u_{i,j-1}}{\Delta y^2}
$$

Substitution into Laplace's equation gives

$$
\boxed{
\frac{u_{i+1,j}-2u_{i,j}+u_{i-1,j}}{\Delta x^2}
+
\frac{u_{i,j+1}-2u_{i,j}+u_{i,j-1}}{\Delta y^2}=0}
$$

For equal grid spacing $h$

$$
\boxed{u_{i,j}
=\frac14
(u_{i+1,j}+u_{i-1,j}+u_{i,j+1}+u_{i,j-1})}
$$

Each interior value is the average of its four neighbours, reflecting the
smoothness of a harmonic field

For unequal spacing

$$
\boxed{
u_{i,j}=
\frac{
(u_{i+1,j}+u_{i-1,j})/\Delta x^2
+(u_{i,j+1}+u_{i,j-1})/\Delta y^2
}{2/\Delta x^2+2/\Delta y^2}}
$$

## Matrix Assembly

With $m$ nodes in the $x$ direction, map the grid index $(i,j)$ to

$$
\boxed{p=i+jm}
$$

Then

| Grid node | Vector index |
| --------- | ------------ |
| $(i,j)$   | $p$          |
| $(i+1,j)$ | $p+1$        |
| $(i-1,j)$ | $p-1$        |
| $(i,j+1)$ | $p+m$        |
| $(i,j-1)$ | $p-m$        |

For equal spacing, an interior row of $A\mathbf u=\mathbf b$ contains

$$
A_{p,p}=-\frac4{h^2}
$$

$$
A_{p,p\pm1}=\frac1{h^2},
\qquad
A_{p,p\pm m}=\frac1{h^2}
$$

and $b_p=0$ for Laplace's equation

For a Dirichlet boundary node

$$
A_{p,p}=1,
\qquad
b_p=u_b
$$

For a right-boundary Neumann condition

$$
A_{p,p}=\frac1{\Delta x},
\qquad
A_{p,p-1}=-\frac1{\Delta x},
\qquad
b_p=g
$$

> [!NOTE] Do not wrap row neighbours
>
> The vector indices $p-1$ and $p+1$ are valid horizontal neighbours only when
> they remain on the same grid row

## Direct and Iterative Solutions

After discretisation, the PDE becomes a linear system

$$
A\mathbf u=\mathbf b
$$

Small systems can use Gaussian elimination or LU decomposition

Large grids produce sparse matrices and favour iterative methods such as
Jacobi, Gauss-Seidel or successive over-relaxation

### Matrix-Free Gauss-Seidel

For equal spacing, sweep through interior nodes using the latest available values

```python
for sweep in range(maximum_sweeps):
    largest_change = 0.0
    for j in range(1, ny - 1):
        for i in range(1, nx - 1):
            old = values[j, i]
            values[j, i] = 0.25 * (
                values[j, i + 1]
                + values[j, i - 1]
                + values[j + 1, i]
                + values[j - 1, i]
            )
            largest_change = max(
                largest_change,
                abs(values[j, i] - old),
            )
    if largest_change < tolerance:
        break
```

The update uses new values on the already swept side and old values elsewhere,
so it is Gauss-Seidel rather than Jacobi

### Residual Check

The change between sweeps is useful, but the discrete residual directly tests
the governing equations

$$
r_{i,j}=
\frac{u_{i+1,j}-2u_{i,j}+u_{i-1,j}}{\Delta x^2}
+
\frac{u_{i,j+1}-2u_{i,j}+u_{i,j-1}}{\Delta y^2}
$$

A converged solution should have a small residual at every interior node and
satisfy every boundary equation

## Maximum Principle

For Laplace's equation, an interior maximum or minimum cannot exceed the extrema
imposed on the boundary unless the solution is constant

This gives a useful error check

$$
\min_{\partial\Omega}u
\le u(x,y)\le
\max_{\partial\Omega}u
$$

An interior value outside the boundary range usually signals an assembly,
indexing or convergence error

## Exam Method

1. draw the grid and label $(i,j)$ directions
2. identify interior and boundary nodes
3. write the five-point stencil before substituting numbers
4. map $(i,j)$ to $p=i+jm$ if a matrix is required
5. create one equation per unknown node
6. replace boundary rows with Dirichlet or Neumann equations
7. solve using the requested direct or iterative method
8. reshape the vector consistently and check boundaries, residuals and the
   maximum principle

> [!TIP] Common exam traps
>
> - treating an elliptic problem as a time-marching problem
> - omitting the grid-spacing factors when $\Delta x\ne\Delta y$
> - applying an interior stencil at a boundary node
> - mapping with $p=j+in_x$ after defining $p=i+jn_x$
> - placing coefficients in wrapped neighbours at the end of a row
> - stopping after a fixed sweep count without checking convergence
