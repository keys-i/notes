# Week 4 - Numerical Integration

## Quadrature

Numerical integration, or **quadrature**, estimates a definite integral from
function values

$$
I=\int_a^b f(x)\,dx
\approx
\sum_{k=0}^{n-1}w_kf(x_k)
$$

| Symbol | Meaning                                                |
| ------ | ------------------------------------------------------ |
| $x_k$  | Quadrature nodes where the function is evaluated       |
| $w_k$  | Weights applied to the function values                 |
| $n$    | Number of function evaluations                         |
| $R_n$  | Difference between the exact integral and the estimate |

Use numerical integration when

- only tabulated values of $f$ are available
- the antiderivative is difficult or impossible to obtain
- $f$ is produced by a simulation or other black box
- an engineering quantity is defined as an accumulated total or average

> [!NOTE] Start with the data
>
> Equally spaced tabulated data restricts the methods that can be used
>
> If $f(x)$ can be evaluated anywhere, Gaussian and adaptive methods become
> available

## Newton-Cotes Rules

Newton-Cotes rules integrate an interpolating polynomial through equally
spaced nodes

Let

$$
x_k=a+kh,
\qquad
h=\frac{b-a}{n-1}
$$

### Trapezoidal Rule

Fit a straight line through the two endpoints

$$
\int_{x_0}^{x_1}f(x)\,dx
\approx
\frac{h}{2}(f_0+f_1)
$$

The one-panel error is

$$
R=-\frac{h^3}{12}f''(\xi)
$$

so the rule is exact for polynomials of degree at most $1$

### Simpson's $1/3$ Rule

Fit a quadratic through three points spanning two equal panels

$$
\int_{x_0}^{x_2}f(x)\,dx
\approx
\frac{h}{3}(f_0+4f_1+f_2)
$$

$$
R=-\frac{h^5}{90}f^{(4)}(\xi)
$$

Although it uses a quadratic interpolant, symmetry makes it exact for every
cubic polynomial

### Simpson's $3/8$ Rule

Fit a cubic through four points spanning three equal panels

$$
\int_{x_0}^{x_3}f(x)\,dx
\approx
\frac{3h}{8}(f_0+3f_1+3f_2+f_3)
$$

$$
R=-\frac{3h^5}{80}f^{(4)}(\xi)
$$

### Degree of Precision

The degree of precision is the highest polynomial degree integrated exactly

| Closed Newton-Cotes points $n$ | Degree of precision |
| -----------------------------: | ------------------: |
|                       Even $n$ |               $n-1$ |
|                        Odd $n$ |                 $n$ |

> [!EXAMPLE]- Identify a rule from exactness
> A quadrature routine integrates a degree-$5$ polynomial exactly
>
> - A closed Newton-Cotes rule needs at least $5$ points because the $5$-point
>   rule has degree of precision $5$
> - Gaussian quadrature needs at least $3$ points because its degree of
>   precision is $2n-1=5$
>
> Exact output alone does not distinguish between these possibilities

## Composite Quadrature

High-order interpolation at many equally spaced nodes can oscillate and may
have large positive and negative weights

Composite quadrature instead divides $[a,b]$ into $N$ panels and repeatedly
uses a low-order rule

$$
a=x_0<x_1<\cdots<x_N=b,
\qquad
h=\frac{b-a}{N}
$$

### Composite Trapezoidal Rule

$$
\int_a^b f(x)\,dx
\approx
\frac{h}{2}
\left[
f_0+2\sum_{i=1}^{N-1}f_i+f_N
\right]
$$

The global error is

$$
R=-\frac{b-a}{12}h^2f''(\xi)=O(h^2)
$$

### Composite Simpson's $1/3$ Rule

The number of panels $N$ must be even

$$
\int_a^b f(x)\,dx
\approx
\frac{h}{3}
\left[
f_0
+4\sum_{\substack{i=1\\i\text{ odd}}}^{N-1}f_i
+2\sum_{\substack{i=2\\i\text{ even}}}^{N-2}f_i
+f_N
\right]
$$

$$
R=-\frac{b-a}{180}h^4f^{(4)}(\xi)=O(h^4)
$$

### Composite Simpson's $3/8$ Rule

The number of panels $N$ must be divisible by $3$

$$
\int_a^b f(x)\,dx
\approx
\frac{3h}{8}
\left[
f_0
+3\sum_{i\not\equiv0\pmod3}f_i
+2\sum_{\substack{i\equiv0\pmod3\\0<i<N}}f_i
+f_N
\right]
$$

> [!EXAM] Composite-rule workflow
>
> 1. Count **panels**, not points, using $N=n_{\text{points}}-1$
> 2. Check the divisibility requirement before choosing Simpson's rule
> 3. Write the weight pattern before substituting values
> 4. Multiply by any averaging factor outside the integral
> 5. State the global error order, not the one-panel error order

## Gaussian Quadrature

Gaussian quadrature chooses both the nodes and the weights

An $n$-point Gauss-Legendre rule has degree of precision

$$
2n-1
$$

This achieves high accuracy with few function evaluations, but the function
must be evaluable at the prescribed nonuniform nodes

### Standard Interval

Gauss-Legendre rules are defined on $[-1,1]$

| Points | Nodes $t_i$                                     | Weights $w_i$                          | Exact through degree |
| -----: | ----------------------------------------------- | -------------------------------------- | -------------------: |
|    $2$ | $\displaystyle\pm\frac{1}{\sqrt3}$              | $1,1$                                  |                  $3$ |
|    $3$ | $\displaystyle-\sqrt{\frac35},0,\sqrt{\frac35}$ | $\displaystyle\frac59,\frac89,\frac59$ |                  $5$ |

### Mapping $[a,b]$ to $[-1,1]$

Use

$$
x=\frac{b-a}{2}t+\frac{a+b}{2},
\qquad
dx=\frac{b-a}{2}\,dt
$$

Therefore

$$
\int_a^b f(x)\,dx
=
\frac{b-a}{2}
\int_{-1}^{1}
f\left(\frac{b-a}{2}t+\frac{a+b}{2}\right)dt
$$

The quadrature estimate is

$$
I\approx
\frac{b-a}{2}
\sum_{i=1}^{n}w_i
f\left(\frac{b-a}{2}t_i+\frac{a+b}{2}\right)
$$

> [!WARNING] Common Gaussian error
>
> Mapping the nodes without multiplying the final sum by $(b-a)/2$ gives an
> answer for the wrong interval

<!-- -->

> [!EXAMPLE]- Integrate $\sin x$ on $[0,\pi/2]$
> The exact value is $1$
>
> | Rule               |  Estimate | Absolute error |
> | ------------------ | --------: | -------------: |
> | Trapezoidal        | $0.78540$ |      $0.21460$ |
> | Simpson's $1/3$    | $1.00228$ |      $0.00228$ |
> | Two-point Gaussian | $0.99847$ |      $0.00153$ |
>
> For the same number of evaluations, the Gaussian rule uses its nodes more
> effectively

## Adaptive Integration

A uniform panel width wastes work where $f$ is smooth and may be inadequate
where $f$ changes rapidly

Adaptive integration estimates local error and subdivides only where needed

One simple strategy compares low- and high-order estimates

```text
integrate(f, a, b, tolerance):
    low = three_point_rule(f, a, b)
    high = five_point_rule(f, a, b)
    if abs(high - low) <= tolerance:
        return high
    midpoint = (a + b) / 2
    return integrate(f, a, midpoint, tolerance / 2) \
         + integrate(f, midpoint, b, tolerance / 2)
```

Practical implementations also need

- a maximum recursion depth or minimum panel width
- reuse of function evaluations after subdivision
- a tolerance allocation across child intervals
- protection against round-off dominating on tiny panels

## Choosing a Method

| Situation                                               | Good first choice                                |
| ------------------------------------------------------- | ------------------------------------------------ |
| Equally spaced tabulated data                           | Composite trapezoidal or Simpson's rule          |
| Smooth explicit function with few evaluations available | Gaussian quadrature                              |
| Localised sharp changes                                 | Adaptive quadrature                              |
| Many points over a large interval                       | Composite low-order rule                         |
| Noisy measurements                                      | A low-order composite rule with error discussion |

---

> [!NOTE] Key ideas
>
> - Quadrature replaces an integral with a weighted sum of function values
> - Composite low-order rules avoid the problems of one high-order interpolant
> - Composite trapezoidal error is $O(h^2)$
> - Composite Simpson's $1/3$ error is $O(h^4)$
> - An $n$-point Gaussian rule is exact through degree $2n-1$
> - Gaussian nodes must be mapped from $[-1,1]$ to the physical interval
> - Adaptive methods spend evaluations where the integrand is hardest
