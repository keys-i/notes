# Week 8 - Nonlinear Equations

## Root-Finding Problems

Rewrite a nonlinear engineering model in standard form

$$
f(x)=0
$$

The solution $r$ is a root satisfying $f(r)=0$

Nonlinear equations generally require an initial guess and an iterative method

Before iterating

1. derive $f(x)$ from the physical balance
2. identify the physically meaningful domain
3. inspect or sample the function
4. estimate how many roots may exist
5. choose a method suited to the available information

> [!EXAMPLE]- Thermocouple heat balance
> At steady state, convection from a hot gas balances radiation to the wall
>
> $$
> hA(T_g-T_c)
> =
> \sigma\epsilon A(T_c^4-T_w^4)
> $$
>
> Cancel $A$ and move all terms to one side
>
> $$
> f(T_c)
> =
> h(T_g-T_c)
> -\sigma\epsilon(T_c^4-T_w^4)
> =0
> $$
>
> The model has now become a root-finding problem in $T_c$

## Bracketing

A continuous function has at least one root in $[a,b]$ if

$$
f(a)f(b)<0
$$

The sign change brackets a root

A search can expand an initial interval in the direction with smaller
$|f(x)|$, or subdivide a broad interval to find several sign changes

> [!WARNING] Sign changes have limits
>
> - a discontinuity may also produce a sign change
> - an even-multiplicity root may touch zero without changing sign
> - a wide bracket may contain more than one root

## Bisection

Bisection repeatedly halves a valid bracket

1. compute $m=(a+b)/2$
2. if $f(a)f(m)<0$, set $b=m$
3. otherwise set $a=m$
4. stop when the bracket is sufficiently small

```python
def bisect(f, a, b, tolerance):
    fa = f(a)
    fb = f(b)
    if fa == 0:
        return a
    if fb == 0:
        return b
    if fa * fb > 0:
        raise ValueError("interval must bracket a root")

    while b - a > 2 * tolerance:
        midpoint = (a + b) / 2
        fm = f(midpoint)
        if fm == 0:
            return midpoint
        if fa * fm < 0:
            b = midpoint
            fb = fm
        else:
            a = midpoint
            fa = fm

    return (a + b) / 2
```

After $n$ bisections

$$
|r-m_n|
\le
\frac{b_0-a_0}{2^{n+1}}
$$

To guarantee $|r-m_n|\le\epsilon$

$$
n
\ge
\left\lceil
\log_2\left(\frac{b_0-a_0}{2\epsilon}\right)
\right\rceil
$$

Bisection converges linearly and is slow but reliable when its assumptions
hold

## Fixed-Point Iteration

Rearrange

$$
f(x)=0
$$

into

$$
x=g(x)
$$

then iterate

$$
x_{k+1}=g(x_k)
$$

Different algebraic rearrangements have different convergence behaviour even
though they have the same root

Near a fixed point $r=g(r)$

$$
e_{k+1}\approx g'(r)e_k
$$

A useful local convergence condition is

$$
|g'(x)|<1
$$

throughout a neighbourhood containing the iterates

If $|g'|>1$, errors grow and the iteration usually diverges

## Convergence Order

Let

$$
e_k=x_k-r
$$

A method has order $\alpha$ if, near the root

$$
|e_{k+1}|\approx C|e_k|^\alpha
$$

|        Order | Name        | Behaviour                                        |
| -----------: | ----------- | ------------------------------------------------ |
|          $1$ | Linear      | A roughly constant fraction of error remains     |
| $1<\alpha<2$ | Superlinear | Faster than linear                               |
|          $2$ | Quadratic   | Correct digits roughly double near a simple root |

## Newton's Method

Linearise $f$ at $x_k$

$$
0
\approx
f(x_k)+f'(x_k)(x_{k+1}-x_k)
$$

giving

$$
x_{k+1}
=
x_k-\frac{f(x_k)}{f'(x_k)}
$$

Newton's method is quadratically convergent near a simple root when the
starting guess is suitable

```python
def newton(f, derivative, x, tolerance, max_iterations=100):
    for _ in range(max_iterations):
        value = f(x)
        if abs(value) <= tolerance:
            return x
        slope = derivative(x)
        if abs(slope) < 1.0e-14:
            raise RuntimeError("derivative is too small")
        x -= value / slope
    raise RuntimeError("Newton iteration did not converge")
```

Newton can fail when

- $f'(x_k)$ is zero or very small
- the initial guess is outside the root's basin of attraction
- an iterate leaves the physical domain
- the function has a multiple root
- the iteration cycles or diverges

> [!EXAMPLE]- Cube root of $N$
> For
>
> $$
> f(x)=x^3-N,
> \qquad
> f'(x)=3x^2
> $$
>
> Newton's update becomes
>
> $$
> x_{k+1}
> =
> \frac23x_k+\frac{N}{3x_k^2}
> $$

## Secant Method

Approximate the derivative using the last two iterates

$$
f'(x_k)
\approx
\frac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}}
$$

The update is

$$
x_{k+1}
=
x_k
-f(x_k)
\frac{x_k-x_{k-1}}
{f(x_k)-f(x_{k-1})}
$$

Properties

- requires two initial guesses
- does not require an analytical derivative
- converges superlinearly with order about $1.618$
- does not preserve a root bracket
- fails if successive function values are equal or nearly equal

## False Position

False position uses the same secant-line intersection but always keeps the
pair of points that brackets the root

It is usually more reliable than the secant method but may converge more
slowly if one bracket endpoint barely moves

## Method Comparison

| Method         | Initial information    | Derivative            | Keeps bracket |       Typical order |
| -------------- | ---------------------- | --------------------- | ------------- | ------------------: |
| Bisection      | Sign-changing interval | No                    | Yes           |                 $1$ |
| Fixed point    | One guess and $g(x)$   | Through $g'$ analysis | No            | $1$ when convergent |
| Newton         | One good guess         | Yes                   | No            |                 $2$ |
| Secant         | Two guesses            | No                    | No            |             $1.618$ |
| False position | Sign-changing interval | No                    | Yes           |      Usually linear |

> [!EXAM] Choose from the evidence
>
> - use bisection when a valid bracket and guaranteed progress matter
> - use Newton when $f'$ is available and a good initial guess is known
> - use secant when derivatives are unavailable but fast local convergence is
>   useful
> - analyse $|g'|$ before trusting a fixed-point rearrangement

## Stopping and Verification

Useful tests include

$$
|f(x_k)|\le\epsilon_f
$$

$$
|x_k-x_{k-1}|
\le
\epsilon_x(1+|x_k|)
$$

Also enforce a maximum iteration count

A small step alone is not enough because a method may stagnate away from a
root

After stopping

- substitute the answer into the original physical balance
- check units and the physically meaningful range
- report the residual $f(x)$
- state whether convergence matched the expected order

> [!EXAM] Hand iteration layout
>
> | $k$ | $x_k$ | $f(x_k)$ | $f'(x_k)$ or bracket | $x_{k+1}$ |
> | --: | ----: | -------: | -------------------: | --------: |
>
> Keep unrounded calculator values between iterations and round only the
> displayed result

---

> [!NOTE] Key ideas
>
> - Convert the engineering model to $f(x)=0$
> - A sign-changing interval brackets a root of a continuous function
> - Bisection is linearly convergent but dependable
> - Fixed-point convergence depends on the chosen rearrangement
> - Newton is quadratically convergent near a suitable simple root
> - Secant avoids analytical derivatives and converges superlinearly
> - Always verify the residual and the physical meaning of the result
