# Week 11 — Second-Order Wave Equation

## Governing equation

$$
\frac{\partial^2u}{\partial t^2}
=c^2\frac{\partial^2u}{\partial x^2}
$$

Define the Courant number

$$
C=c\frac{\Delta t}{\Delta x}
$$

## Centred update

$$
u_i^{n+1}
=
2u_i^n-u_i^{n-1}
+C^2\left(u_{i+1}^n-2u_i^n+u_{i-1}^n\right)
$$

For zero initial velocity, the first time level is

$$
u_i^1
=
u_i^0
+\frac{C^2}{2}
\left(u_{i+1}^0-2u_i^0+u_{i-1}^0\right)
$$

## Implementation

```python
previous = initial.copy()
current = first_step(initial, courant)

for _ in range(1, time_steps):
    following = current.copy()
    following[1:-1] = (
        2 * current[1:-1]
        - previous[1:-1]
        + courant**2 * (current[2:] - 2 * current[1:-1] + current[:-2])
    )
    following[0] = left_boundary
    following[-1] = right_boundary
    previous, current = current, following
```

## Checks

- require $|C|\le1$ in one dimension
- initialise the first step from the stated initial velocity
- keep three distinct time levels
- confirm that the wave travels at speed $c$
- check amplitude and phase error as the grid is refined
