# Week 9 — Bicycle Frame Optimisation

## Tube geometry

For outer diameter $D$ and inner diameter $d$

$$
A(D,d)=\frac{\pi}{4}(D^2-d^2)
$$

$$
I(D,d)=\frac{\pi}{64}(D^4-d^4)
$$

Mass per unit length is $\rho A$

Use the stiffness or stress requirement to eliminate one variable, then
minimise the remaining one-dimensional objective over its feasible interval

## Golden-section search

$$
\tau=\frac{\sqrt5-1}{2}
$$

```python
def golden_minimum(function, left, right, tolerance=1.0e-8):
    ratio = (np.sqrt(5.0) - 1.0) / 2.0
    x1 = right - ratio * (right - left)
    x2 = left + ratio * (right - left)
    f1 = function(x1)
    f2 = function(x2)

    while right - left > tolerance:
        if f1 > f2:
            left = x1
            x1, f1 = x2, f2
            x2 = left + ratio * (right - left)
            f2 = function(x2)
        else:
            right = x2
            x2, f2 = x1, f1
            x1 = right - ratio * (right - left)
            f1 = function(x1)
    return 0.5 * (left + right)
```

## Checks

- use one consistent length unit throughout
- reject $d<0$ and $d\ge D$
- verify stress, stiffness and geometry constraints after optimisation
- plot the objective to check that the chosen bracket is unimodal
- compare the optimum against both bracket endpoints
