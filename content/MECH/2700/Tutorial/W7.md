# Week 7 — Falling Through the Stratosphere

## State equations

Take upward displacement as positive and let $v=dh/dt$

$$
\frac{dh}{dt}=v
$$

$$
\frac{dv}{dt}
=
-g-
\frac{\rho(h)C_DA}{2m}v|v|
$$

The term $v|v|$ makes drag oppose the direction of motion

An exponential atmosphere model is

$$
\rho(h)=\rho_0e^{-h/H}
$$

## Right-hand side

```python
def derivative(_time, state, rho0, scale_height, drag, area, mass, gravity):
    height, velocity = state
    density = rho0 * np.exp(-height / scale_height)
    acceleration = -gravity - density * drag * area * velocity * abs(velocity) / (2 * mass)
    return np.array([velocity, acceleration])
```

## RK4 step

```python
def rk4_step(function, time, state, step, *parameters):
    k1 = function(time, state, *parameters)
    k2 = function(time + step / 2, state + step * k1 / 2, *parameters)
    k3 = function(time + step / 2, state + step * k2 / 2, *parameters)
    k4 = function(time + step, state + step * k3, *parameters)
    return state + step * (k1 + 2 * k2 + 2 * k3 + k4) / 6
```

Stop when the height crosses zero and interpolate between the final two states
to estimate impact time and velocity

## Checks

- with $C_D=0$, acceleration remains $-g$
- drag reduces the magnitude of a downward velocity
- smaller time steps converge towards the same trajectory
- compare Euler, RK2 and RK4 at equal step sizes
- do not continue the atmospheric model below ground level
