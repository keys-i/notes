# Week 4 — Vortex-Pressure Integration

## Data and Program Flow

The pressure samples come from a Lattice–Boltzmann vortex-shedding simulation
and are tabulated rather than available as a closed-form function

`fit_vortex_pressure.py` drives the calculation. It loads the pressure data,
builds the pressure fit, calls the quadrature routines and reports the integral
and evaluation time

The numerical integration is split between

- `comp_quad.py` for composite quadrature over a chosen partition
- `quadlow.py` for the low-order rule used on each subinterval

## Adaptive Estimate

For a subinterval $[a,b]$, evaluate a coarse estimate $Q_1$ and a refined
estimate $Q_2$ formed by splitting the interval in two

$$
Q_1=Q[a,b],
\qquad
Q_2=Q[a,m]+Q[m,b],
\qquad
m=\frac{a+b}{2}
$$

Accept the refined estimate when

$$
|Q_2-Q_1|\leq \varepsilon_{a,b}
$$

Otherwise apply the same test recursively to $[a,m]$ and $[m,b]$. Split the
parent tolerance between the children so the accepted local errors remain
within the requested global tolerance

```python
def adaptive_quad(rule, function, left, right, tolerance, minimum_width):
    middle = 0.5 * (left + right)
    coarse = rule(function, left, right)
    refined = rule(function, left, middle) + rule(function, middle, right)

    if abs(refined - coarse) <= tolerance or right - left <= minimum_width:
        return refined

    return adaptive_quad(
        rule, function, left, middle, tolerance / 2, minimum_width
    ) + adaptive_quad(rule, function, middle, right, tolerance / 2, minimum_width)
```

The minimum-width condition is essential: finite-precision arithmetic can make
the error test stall even after further subdivision stops changing the points
