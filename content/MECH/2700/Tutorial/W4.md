# Week 4 — Numerical Integration

## Start from the available data

For tabulated values $(x_i,f_i)$, first check that the spacing is uniform

$$
h=x_{i+1}-x_i
$$

With $N$ panels there are $N+1$ points

## Composite trapezoidal rule

$$
I_T=
h\left[
\frac{f_0}{2}
+\sum_{i=1}^{N-1}f_i
+\frac{f_N}{2}
\right]
$$

```python
def trapezoidal(values, h):
    return h * (0.5 * values[0] + values[1:-1].sum() + 0.5 * values[-1])
```

## Composite Simpson rule

$N$ must be even

$$
I_S=\frac{h}{3}
\left[
f_0+f_N
+4\sum_{i\text{ odd}}f_i
+2\sum_{i\text{ even},\ 0<i<N}f_i
\right]
$$

```python
def simpson(values, h):
    panels = len(values) - 1
    if panels % 2:
        raise ValueError("Simpson rule needs an even panel count")
    return h / 3 * (
        values[0]
        + values[-1]
        + 4 * values[1:-1:2].sum()
        + 2 * values[2:-1:2].sum()
    )
```

## Two-point Gaussian rule

Map $t\in[-1,1]$ to $x\in[a,b]$

$$
x(t)=\frac{a+b}{2}+\frac{b-a}{2}t
$$

$$
I_G\approx\frac{b-a}{2}
\left[
f\left(x\left(-\frac{1}{\sqrt3}\right)\right)
+f\left(x\left(\frac{1}{\sqrt3}\right)\right)
\right]
$$

## Checks

- count panels before selecting a rule
- retain the $(b-a)/2$ mapping factor for Gaussian quadrature
- halve $h$ and compare successive estimates
- expect trapezoidal error to reduce by about $4$ and Simpson error by about
  $16$ in the asymptotic range
