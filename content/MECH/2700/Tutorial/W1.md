# Week 1 — Python Refresher and Transient Cooling

## Model

A steel rod of length $L=\pi\ \mathrm{m}$ cools according to

$$
\frac{\partial u}{\partial t}
=
\alpha\frac{\partial^2u}{\partial x^2},
\qquad
\alpha=10^{-4}\ \mathrm{m^2\,s^{-1}}
$$

where $u=T-T_{\mathrm{ambient}}$

Both ends are insulated and the initial temperature difference is

$$
u(x,0)=100x
$$

The series solution is

$$
u(x,t)=50\pi+
\sum_{k=0}^{\infty}
-\frac{400}{(2k+1)^2\pi}
e^{-\alpha(2k+1)^2t}
\cos((2k+1)x)
$$

The forging threshold occurs when $u(\pi,t)=200\ \mathrm{K}$

## Evaluate the series

```python
from numpy import cos, exp, pi


def term(k, x, t, alpha):
    odd = 2 * k + 1
    return -400.0 / (odd**2 * pi) * exp(-alpha * odd**2 * t) * cos(odd * x)


def temperature_difference(x, t, alpha=1.0e-4, tolerance=1.0e-6):
    value = 50.0 * pi
    for k in range(100):
        contribution = term(k, x, t, alpha)
        value += contribution
        if abs(contribution) <= tolerance:
            return value
    raise RuntimeError("series did not converge")
```

## Find the safe time

Plot $u(\pi,t)$ first to bracket the threshold, then solve

$$
f(t)=u(\pi,t)-200=0
$$

with bisection

```python
def threshold_time(left, right, tolerance=1.0e-3):
    while right - left > tolerance:
        middle = 0.5 * (left + right)
        if temperature_difference(pi, middle) > 200.0:
            left = middle
        else:
            right = middle
    return 0.5 * (left + right)
```

## Checks

- the last retained series term is smaller than the tolerance
- increasing the maximum term count does not change the result
- $u(\pi,t)$ decreases towards its long-time value $50\pi$
- the root remains inside the original time bracket
